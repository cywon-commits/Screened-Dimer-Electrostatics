# 계산 의뢰서 C: 경계 자유에너지 예측의 사전 검증 (2026-11-25)

## 목적
전체 모형(빈칸을 모든 칸에 허용)과 경계 모형의 차이 D = Q_un(전체) − Q_un(경계)는 N → ∞에서 상수 D∞(x)로 간다는
예측이 있다(`scripts/full_vs_boundary/README.md`). 의뢰서 B의 자료(x = 0.7, 0.5, 0.4152)는 예측과 맞았지만, 그 비교는
자료가 이미 있는 상태에서 한 것이다. 이 의뢰는 **자료가 없는 x에서 예측을 먼저 적어 두고** 확인한다.

예측(커밋 `9e18bb8`의 `data/full_vs_boundary/D_inf.csv`에 기록, 다이아몬드 자료를 쓰지 않음):

| x | D∞ (예측) | σ∞(x) |
|---|---|---|
| 0.6 | −0.586 | 0.799931 |
| 0.8 | −0.234 | 0.924080 |

판정 기준(계산 전에 고정): 각 x에서 가장 큰 두 크기의 D를 1/N에 대해 선형 외삽한 값이 D∞와 2σ 안에서 맞으면 확인,
벗어나면 불일치로 보고한다. 어느 쪽이든 그대로 보고한다.

## 계산할 점 (5개)
z = 2^(−xN/2). 경계 모형의 Q_un은 정확값이다(`scripts/full_vs_boundary/qb.py`).

| x | N | z | Q_un(경계, 정확) | (N/2)σ∞ |
|---|---|---|---|---|
| 0.6 | 24 | 0.006801176276 | 8.9452 | 9.5992 |
| 0.6 | 32 | 0.001288581944 | 12.1492 | 12.7989 |
| 0.6 | 40 | 0.000244140625 | 15.3516 | 15.9986 |
| 0.8 | 24 | 0.001288581944 | 10.4704 | 11.0890 |
| 0.8 | 32 | 0.0001402219672 | 14.1662 | 14.7853 |

- 사다리는 세 개면 된다. N = 24 하나에 z = 1.2886e-3과 6.8012e-3을, N = 32 하나에 1.4022e-4와 1.2886e-3을 넣는다.
  N = 40은 z = 2.4414e-4 하나다. 위의 z가 사다리에 정확히 들어가야 한다(`LADDER_EXTRA`).
- 모든 z가 10⁻⁴ 이상이다. 의뢰서 B에서 지역 갱신으로 수렴한 범위(B32의 4.3e-4, B48의 2.4e-4)와 같다.
- x = 0.8, N = 40 (z = 1.5e-5)은 **돌리지 않는다.** 의뢰서 B에서 평형에 이르지 못한 z다.
- 참고: x = 0.6, N = 20 (z = 2⁻⁶)의 정확값은 Q_un(전체) = 6.4330, Q_un(경계) = 7.3423, D = −0.909다.

우선순위: N = 32 사다리(두 x를 한 번에) → N = 24 사다리 → N = 40.

## 조건
- 코드와 절차는 의뢰서 B와 같다: `taskA_results/scripts/aztec_pt_taskA.c`, `taskB_results/scripts/` (`run_pt_B.sh`, `ladder.py`, `queue_B.sh`, `fixedx_table.py`).
  `fixedx_table.py`의 `SIG`에 0.6: 0.799931, 0.8: 0.924080을 추가한다.
- 씨앗 8개(차가운 시작 4, 뜨거운 시작 4). 오차는 씨앗 간 산포로 잡는다. 씨앗 4개는 오차를 과소추정한 전례가 있다(의뢰서 B 보고서 2절).
- 목표 오차: N = 24, 32에서 ±0.010, N = 40에서 ±0.015 이하.
- 스윕(평형 + 측정): N = 24는 1×10⁶ + 4×10⁶, N = 32는 2×10⁶ + 8×10⁶, N = 40은 3×10⁶ + 1.2×10⁷. 목표 오차에 못 미치면 측정을 늘린다.
- 사다리: 목표 교환 수락률 0.4, 상단 0.1. 실제 최소 수락률 0.2 이상.
- 수렴 판정: 차가운/뜨거운 시작의 평균이 합성 오차의 3배 안에서 맞아야 한다(`fixedx_table.csv`의 `converged` 열). 맞지 않는 점은 수치를 쓰지 않고 범위만 보고한다.
