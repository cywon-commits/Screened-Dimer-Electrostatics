# 계산 의뢰서 B: 전체 모형의 고정 x 계열 (2026-11-20)

## 목적
빈칸을 경계 칸에만 허용한 모형은 정확히 풀렸다(`corner_islands/exact_sol.py`). 논문의 주제는 빈칸을 모든 칸에
퓨개시티 z로 허용한 모형이다. 두 모형이 스케일링 극한에서 같은 σ∞(x)를 갖는지 확인한다.

- x = N*/N = 2 log2(1/z) / N 을 고정하고 N을 키운다.
- 검증할 예측: Q_un(N, z) − (N/2)·σ∞(x) 가 N이 커져도 유계인 상수로 수렴한다.
- 지금까지: x = 0.4152 에서 N = 16, 32, 48, 64 → −1.82, −2.31, −2.19, −2.12 (한 x에서만 확인).

## 계산할 점
`scripts/aztec/aztec_pt.c` (z 방향 병렬 템퍼링). 아래 z가 사다리에 정확히 들어가야 한다.
`REQ="z1 z2 ..." scripts/aztec/run_pt_req.sh N SEED R ZMIN ZMAX THERM MEAS OUTDIR` 를 쓰면 REQ의 z가 사다리에 삽입된다.

| x | N | z = 2^(−xN/2) |
|---|---|---|
| 0.3 | 32 | 0.0358968 |
| 0.3 | 48 | 0.00680118 |
| 0.3 | 64 | 0.00128858 |
| 0.3 | 96 | 4.6256e-05 |
| 0.4152 | 96 | 1e-06 |
| 0.5 | 32 | 0.00390625 |
| 0.5 | 48 | 0.000244141 |
| 0.5 | 64 | 1.52588e-05 |
| 0.7 | 24 | 0.00296038 |
| 0.7 | 32 | 0.000425074 |
| 0.7 | 48 | 8.76387e-06 |

우선순위: x = 0.5 (N = 32, 48, 64) → x = 0.3 (N = 32, 48, 64) → x = 0.7 → N = 96 두 점.
N = 96은 비용이 크므로(기존 추정 약 1,000 코어-시간) 앞의 것을 보고한 뒤 진행 여부를 묻는다.

## 조건
- 독립 시드 4개 이상. 오차는 시드 간 산포로 잡는다(작은 z에서 단일 실행의 블록 오차는 3–5배 과소추정).
- 목표 오차: Q_un 에서 ±0.02 이하.
- 교환 수락률은 사다리 전 구간에서 0.2 이상. 사다리 상단은 0.1까지 둔다.
- 평형화·측정 스윕 수는 기존 과제 A의 같은 N 설정을 따른다.
