# 모서리 점전하 문제의 호도그래프 풀이: 유도 요약

`src/exact_sol.py`(급수 꼴)와 `src/elliptic_sol.py`(타원적분 꼴)가 구현한 해의 유도를 한곳에 모은 노트다(2026-11-25).
결과와 검증은 원고 `manuscript/main.tex`의 IV·V절과 부록 B, 연구 계획 문서 17·18·22·23절에 있다.

## 0. 문제와 규약
- 좌표 (u, v): 모서리 S에서 만나는 두 변 방향, 반변 길이 = 1. S = (0,0), 변 중점 M = (1,0), 중심 O = (1,1). 기본 영역은 삼각형 S–M–O.
- 높이 H: 변 위에서 |∂H/∂u| = 1 − 2ρ_v (ρ_v는 가장자리 칸당 빈칸 밀도). `ckp.ent(s,t)`의 변수는 (s,t) = (h_u − h_v, h_u + h_v), 값은 도미노당 엔트로피.
- 범함수: ln Z/N² = ¼∫ ent(∇H) du dv + (x ln2/4)[H(S)+H(N)−H(W)−H(E)], 경계값은 자유, z = 2^(−xN/2).
- 정류 조건: 내부에서 ∇·j = 0 (j = ∂ent/∂∇H), 빈칸이 있는 변에서 j·n = 0, 얼어붙은 곳에서는 기울기가 최대.

## 1. 호도그래프 변수와 영역 [유도, 일대일 대응은 수치확인]
- 스펙트럼 곡선 1 + z + w − zw = 0, 즉 w = (1+z)/(z−1). 기울기와의 관계: |∂ent/∂h_u| = ½ ln|z|, |∂ent/∂h_v| = ½ ln|w| (부호는 방향 규약).
- 복소 Burgers 해: **v − λ(z) u = Ψ(z)**, λ = 2z/(1−z²), Ψ는 해석함수. u, v가 실수이므로 u = −Im Ψ/Im λ, v = Re Ψ + Re λ · u.
- ζ = (z − i)/(z + i), 역으로 z = i(1+ζ)/(1−ζ). 그러면 λ = iμ, μ = (1−ζ²)/(1+ζ²).
- 삼각형 S–M–O의 액체 부분은 모든 x에서 부채꼴 **{|ζ| < 1, −π/4 < arg ζ < 0}** 이다.

| 시료의 선 | ζ 평면 | 그 위의 조건 | J = (ζ⁴ + ζ⁻⁴)/2 |
|---|---|---|---|
| 중심 O | ζ = 0 (z = i, 평평) | u = v = 1 | J = ∞ |
| 거울선 MO (u = 1) | 실수 ζ = r, 0 < r < r_M | u = 1 | J > J_M |
| 빈칸이 있는 변 SM (v = 0) | 실수 r_M < r < 1 | v = 0, h_v = 0, h_u = (4/π) arctan r | 1 < J < J_M |
| 얼어붙은 모서리의 경계 | 호 ζ = e^(−iφ), 0 < φ < π/4 | z 실수, Ψ 실수 | −1 < J < 1 |
| 대각선 SO (u = v) | 반직선 arg ζ = −π/4 | u = v | J < −1 |

- 실수 ζ = r에서 z = it, t = (1+r)/(1−r)이고 |w| = 1이다. 그래서 h_v = 0이고 빈칸 밀도는 ρ_v = ½ − (2/π) arctan r.
- J는 부채꼴을 반평면으로 편다(ζ⁴가 반원판, 주코프스키 변환이 반평면). 경계 전체가 J의 실수축이다. J = (r⁴ + r⁻⁴)/2 = cosh(4 ln(1/r)).
- x는 점 M의 위치 r_M (또는 J_M) 하나로만 들어온다.

## 2. 경계 조건과 해 [유도, "특이성 없는 해" 선택은 가정]
중심의 자명한 해 Ψ₀ = 1 − λ (u = v = 1)를 빼고 **G = Ψ − 1 + iμ = (v − 1) − iμ(u − 1)** 로 쓴다.

| 구간 | G에 대한 조건 | 이유 |
|---|---|---|
| MO | Im G = 0 | μ 실수, u = 1 |
| SM | Re G = −1 | μ 실수, v = 0 |
| 호 | Im G = 0 | λ = −tan φ 실수, Ψ 실수 (특성선 v + u tan φ = Ψ의 포락선이 얼어붙은 경계) |
| 반직선 | arg G = arg(1 − λ) (mod π) | u = v이면 Ψ = u(1 − λ) |

여기서 1/(ζ + ζ⁻¹)을 떼어 내면 네 조건이 한 함수의 실수 조건으로 바뀐다.

    G = −𝔉(J)/(ζ + ζ⁻¹),   즉   Ψ(ζ) = 1 − iμ − 𝔉(J)/(ζ + ζ⁻¹)

- 호에서 ζ + ζ⁻¹ = 2 cos φ는 실수이고, 반직선에서 arg[1/(ζ + ζ⁻¹)] = arg(1 − λ)다(ζ² = −ir²을 넣으면 둘 다 −π/4 − arg(1 + ζ²)).
  MO에서도 ζ + ζ⁻¹은 실수다. 따라서 **𝔉는 J < 1과 J > J_M에서 실수**다.
- SM에서는 Re G = −1이 **Re 𝔉 = r + 1/r** 이 된다. J = cosh(4 ln(1/r))이므로

      r + 1/r = 2 cosh(¼ arccosh J) ≡ F.

  F(φ) = 2 cosh[¼ arccosh(c₀ − c₁ cos φ)]는 바로 이 경계값이다. c₀ = (1 + J_M)/2, c₁ = (J_M − 1)/2는 절단 [1, J_M]을
  J = c₀ − c₁ cos φ (0 < φ < π)로 매개화한 것이다. φ = 0이 얼어붙은 구간의 끝(r = 1), φ = π가 M이다.
- 따라서 𝔉는 "절단 [1, J_M] 밖에서 해석적이고, 절단 양쪽에서 실수부가 F이며, 나머지 실수축에서 실수이고, 유계"인 함수다.
  절단의 주코프스키 변수 ε (ε + ε⁻¹ = 2(c₀ − J)/c₁, |ε| < 1)로 쓰면

      F(φ) = Σ a_n cos nφ   ⇒   𝔉(J) = Σ a_n εⁿ,   절단 위에서 𝔉 = F ± iF̃,  F̃ = Σ a_n sin nφ.

- 유계 조건이 "모든 점에서 Ψ 유한"이다. 끝점 J = 1, J_M에서 발산하는 동차해를 더하지 않는다. 이 선택은 가정이고, 결과의
  사후 검증(`verify_sol.py`, `verify_bc.py`)과 열거값과의 일치로 뒷받침된다.
- 읽어 내는 식:
  - MO: v = 1 − 𝔉/(r + 1/r), 𝔉 = Σ a_n εⁿ (ε 실수).
  - SM: u = 1 + F̃/[μ (r + 1/r)] = 1 + (r + 1/r) F̃/(r⁻² − r²), r⁻² − r² = 2√c₁ sin(φ/2).
  - 얼어붙은 길이: d* = u(φ → 0) = 1 + 2 Σ n a_n/√c₁.
  - 얼어붙은 경계: 호에서 T = tan φ, 직선족 v + T u = Ψ(T)의 포락선 u = Ψ′(T), v = Ψ − TΨ′.
- 확인 [수치확인]: 위의 간결한 꼴은 `verify_sol.py`가 쓰는 꼴
  Ψ = 1 − iμ + e^(−iπ/4) √μ (1−J)^(1/4) (J_M−J)^(1/2) Φ(J)와 내부 점에서 10⁻¹⁶까지 같다(`tests/test_core.py`).
  타원적분 꼴(`elliptic_sol.py`)은 Σ a_n εⁿ을 닫힌 꼴로 합한 것이다.

## 3. J_M과 x를 잇는 식 [유도]
모서리 원천의 흐름 보존이다.

1. 범함수의 모서리 항을 변분하면, S를 둘러싼 사분원을 지나는 흐름이 ∮ j·n dℓ = x ln 2다(¼∮ = x ln2/4).
2. 대각선 대칭으로 삼각형 S–M–O 쪽으로 절반 x ln2/2가 들어간다.
3. j는 발산이 없고, SM에서는 j·n = 0(자연 경계 조건), SO에서는 대칭으로 j·n = 0이다. 그러므로 전부 MO를 지난다.
4. MO(u = 1)의 법선은 u 방향이고 j_u = ∂ent/∂h_u = ½ ln|z| = ½ ln t, t = (1+r)/(1−r)다.

       ∫_MO ½ ln t dv = x ln2/2   ⇒   **x ln 2 = ∫_MO ln[(1+r)/(1−r)] dv**

   부분적분하면 x ln 2 = ∫₀^{r_M} v(r) · 2 dr/(1 − r²)다(O에서 ln t = 0, M에서 v = 0).

- 얼어붙은 영역 안에서도 흐름을 나르는 장이 있어야 3번이 성립한다. 그 장을 구성하지는 않았다(원고 VI절 B에 적은 빈틈).
- 정규화 확인 [수치확인]: J_M → 1에서 적분이 ln 2가 되어 x = 1(온전한 다이아몬드)을 준다.
- σ = H(S) − H(M) = ∫₀¹ h du, h = (4/π) arctan r (SM), h = 1 (얼어붙은 구간).

## 3a. 복소 퍼텐셜과 미분 관계 (2026-11-25 추가) [유도 + 수치확인]
dw/w = λ dz/z이므로 **Ω = ½(v ln z − u ln w) − ½∫Ψ dz/z** 는 dΩ = ½(ln z dv − ln w du)를 만족한다. 실수부가 흐름이고,
경로와 무관하다. (이 부분적분은 `cywon-commits/shakti-arctic-design`의 닫힌 정사각형 풀이에서 가져온 것이다.)
dz/z · 1/(ζ + ζ⁻¹) = −½ dP/(P² − 4), P = ζ² + ζ⁻²이므로 x와 σ는 같은 함수 𝔉의 같은 미분형식에 대한 적분이다.

    x ln 2 = ln[(1+r_M)/(1−r_M)] − ∫_{p_M}^{∞} 𝔉 dP/(P² − 4)          (MO 위, 𝔉 실수)
    σ = 1 + (2/π) ∫_{2}^{p_M} F̃ dP/(P² − 4)                           (SM 위, 𝔉 = F + iF̃)

MO 위에서는 3절의 식과 같은 적분이라, 이 꼴만으로 x가 타원적분으로 닫히지는 않는다(𝔉가 대수함수가 아니라 제3종 타원적분이다).
닫히는 것은 **매개변수에 대한 도함수**다. F는 J_M에 의존하지 않으므로 ∂𝔉/∂J_M은 동차 문제의 해다(절단에서 실수부 0,
밖에서 실수, 움직이는 끝점 J_M에서만 제곱근 특이성).

    ∂𝔉/∂J_M = (da₀/dJ_M) · √[(J − 1)/(J − J_M)],     a₀ = 𝔉(∞) = (4√(2p_M)/π) [E(k) − K(k)/2],  k² = (p_M − 2)/(2p_M)

위 두 식에 넣으면 적분이 제1종 완전 타원적분이 된다(k₁ = 2/p_M = 1 − 2k², k₁′ = √(1 − k₁²)).

    d(x ln 2)/dp_M = −(da₀/dp_M) K(k₁)/p_M,       dσ/dp_M = −(2/π)(da₀/dp_M) K(k₁′)/p_M

    **dσ/dx = (2 ln 2/π) · K(k₁′)/K(k₁) = −(2 ln 2/π²) ln q₁**      (q₁은 k₁의 nome)

- 의미: σ는 모서리의 높이(퍼텐셜), x ln 2는 모서리 전하다. dσ/dx는 모서리의 미분 역전기용량이고, 타원 모듈러스 하나의 비로 주어진다.
- x → 0: K′/K ≈ (2/π) ln(4/k₁)에서 dσ/dx ≈ (8 ln2/π²) ln(√2/r_M)이고, x ln2 = (π/ϖ_L) r_M을 넣으면 작은 x 법칙
  σ ≈ (8 ln2/π²) x ln(B/x)의 도함수와 상수 B까지 정확히 같다.
- x → 1: k₁ → 1, K → ∞이라 dσ/dx → 0 (로그로).
- 확인: 유한 차분과 10⁻⁷ 수준에서 일치(`tests/test_core.py`, `elliptic_sol.dsigma_dx`). a₀의 닫힌 꼴과 ∂𝔉/∂J_M의 꼴도 수치로 확인했다.
- 남은 것: x(p_M) 자체는 서로 다른 모듈러스(k와 k₁)의 타원적분 곱을 한 번 적분한 것으로, 닫힌 꼴을 찾지 못했다.

## 4. 다른 경계 자료로 옮길 때
- 그대로 쓸 수 있는 것: Burgers 해의 꼴, ζ와 μ, "변 위에서 ζ가 실수", "얼어붙은 경계에서 |ζ| = 1이고 Ψ가 실수", 자연 경계 조건,
  모서리 원천의 세기와 3절의 흐름 계산.
- 바뀌는 것: 대칭이 줄면 ζ 평면의 영역이 π/4 부채꼴이 아니고, J = (ζ⁴ + ζ⁻⁴)/2 대신 그 영역을 반평면으로 펴는 사상이 필요하다.
  거울선이 아닌 변에서는 u = 1 같은 조건이 없으므로, G의 위상 조건을 구간마다 다시 세워야 한다(1/(ζ + ζ⁻¹) 인수가 그대로
  통한다는 보장이 없다). 매개변수도 하나(J_M)가 아니라 구간 끝점의 수만큼 생기고, 각각 흐름 조건이나 닫힘 조건으로 정한다.
- 이 노트의 풀이는 네 변이 모두 빈칸을 허용하는 경우만 다루고 검증했다.
