# 전체 모형과 경계 모형의 차이: 해석과 검증 (의뢰서 B 후속, 2026-11-25)

의뢰서 B의 질문은 "Q_un(N, z) − (N/2)σ∞(x)가 유계 상수로 수렴하는가"였다. 이 폴더는 그 답을 대규모 계산 없이 구한다.
등급: [유도] 식으로 따라갈 수 있음 · [수치확인] 계산으로 확인 · [논증] 물리적 논증.

## 결론

1. 두 모형의 차이는 가장자리 한 칸당 경계 자유에너지 δg(ρ)이고, Q_un의 차이는 유계 상수로 수렴한다 [유도 + 논증]. log N 항은 없다.

       D∞(x) ≡ lim [Q_un(전체) − Q_un(경계)] = (1/ln 2) · d/dx ∫₀² δg(ρ_x(ℓ)) dℓ

   ρ_x(ℓ)는 정확해(`src/exact_sol.py`)의 가장자리 빈칸 밀도다.
2. δg(ρ)는 한쪽 띠 전달행렬로 0.2% 정밀도로 구했다 [수치확인]. ρ → 0에서 δg ≈ 0.545 tan²(πρ/2)이다.
3. 예측은 다이아몬드의 MC 자료를 쓰지 않으며, 자료와 맞는다 [수치확인].

| x | 예측 D∞ | 자료의 두 점 1/N 외삽 | 마지막 자료점 | N (D − D∞), 마지막 두 크기 |
|---|---|---|---|---|
| 0.7 | −0.388 | −0.31 ± 0.08 | −0.557 (N = 32) | −6.1 ± 0.2, −5.4 ± 0.6 |
| 0.5 | −0.850 | −0.78 ± 0.06 | −1.079 (N = 48) | −12.1 ± 0.3, −11.0 ± 0.9 |
| 0.4152 | −1.155 | −1.23 ± 0.08 | −1.46 (N = 64) | −18.6 ± 0.2, −19.7 ± 1.3 |
| 0.3 | −1.780 | (점근 영역 밖) | −2.376 (N = 64) | −35.0, −38.2 ± 0.6 |

   - 예측값을 고정하면 N (D − D∞)가 마지막 두 크기에서 오차 안에서 일정하다. 즉 D = D∞ + A(x)/N이다.
   - A(x) ≈ −3/x²이다(−5.4, −11, −19, −38). 이 계수는 유도하지 않았다.
   - x = 0.3은 N = 48이 꺾임 위치(N* ≈ 14)라서 두 점 외삽이 의미가 없다.
4. 의뢰서 B의 "N에 대해 단조가 아니다"는 유한 z 효과다. D의 최솟값은 x와 무관하게 N* = xN ≈ 14 ± 2 (z ≈ 5 × 10⁻³)에 있다.
5. 미수렴 점(x = 0.5, N = 64)의 예측: D = −0.850 − 11.5/64 = −1.03, Q_un(경계) = 22.415이므로 **Q_un ≈ 21.4 ± 0.1**.
   보고서의 뜨거운 시작 씨앗(21.2, 22.0)과 맞는다.

## 유도

**차이는 경계 자유에너지다.** 고정 x에서 z = 2^(−xN/2)는 N에 지수적으로 작아 내부의 빈칸 쌍은 사라진다. 남는 차이는
흡착된 빈칸이 몇 칸 안쪽에 앉을 수 있다는 것이고, 이는 국소 상태(빈칸 밀도 ρ)에만 의존한다.

    ln Z_전체 − ln Z_경계 = Σ_{가장자리 칸} δg(ρ) + O(1) = 2N · I(x),   I(x) = ∫₀² δg(ρ_x(ℓ)) dℓ

1차 섭동이므로 ρ_x는 경계 모형의 해를 그대로 쓴다.

**Q_un으로 옮기기.** 빈칸 수는 z ∂ln Z/∂z이고 ln z = −(xN ln 2)/2에서 z∂_z = −(2/(N ln 2)) ∂_x다.
네 변의 합은 −4 I′(x)/ln 2, 변 하나당 −I′(x)/ln 2이고 Q_un = N/2 − Q_edge이므로 D∞ = I′(x)/ln 2다.

- ln Z의 N² 항은 두 모형이 같고 차이는 N 항에서 시작한다. z∂_z가 1/N을 주므로 Q_un의 차이는 O(1)이다.
- ln Z 차이의 O(1) 항 K(x)는 D에 K′(x)/(2N ln 2)를 준다. 자료의 A(x) ≈ −3/x²은 K ≈ 4.2/x에 해당한다.
- δg가 선형(δg = ρ ln λ)이면 퓨개시티의 단순 재규격화이고 D∞ = −σ′(x) log₂λ가 된다. 실제 δg는 ρ²로 시작하므로 그렇지 않다.

**국소 상태가 띠와 같은 이유** [논증]. 빈칸이 있는 가장자리 구간에서는 자연 경계 조건 j·n = 0이 성립하고, 엔트로피 함수의
대칭으로 법선 기울기가 0이다. 접선 기울기는 1 − 2ρ다. 이것은 계단 띠의 균일 상태와 같다. 안쪽으로 d칸 들어간 빈칸의
가중치는 t^d (t = tan(πρ/2))로 줄어 경계층 두께가 유한하다.

## δg(ρ)의 계산 (`onesided.py`)

처음 쓴 방법(`two_sided_strip.py`: 전체 모형 띠와 경계 모형 띠의 자유에너지 차, z = t^(W/2))은 수렴이 느렸다.
원인은 두 가지다. (i) W = 20에서도 ρ ≳ 0.35이면 z ≳ 10⁻²이라 내부에 빈칸 쌍이 남는다. (ii) 같은 z에서 비교하면 상태가
O(1/W)만큼 달라 2(δg′)² sin(πρ)/(πW)의 보정이 붙는다.

고친 방법은 다음과 같다.

- **한쪽 띠:** 왼쪽 가장자리 색의 빈칸은 모든 칸에 허용하고, 반대 색의 빈칸은 오른쪽 가장자리의 가장 바깥 칸에만 허용한다.
  내부에서 중성 쌍이 생길 수 없으므로 z → 0 극한이 O(t^W)의 오차로 얻어진다.
- **같은 빈칸 수에서 비교:** φ(ρ) = ln Λ(z) − 2ρ ln z (Legendre 변환)를 두 모형에서 구해 뺀다. (ii)의 보정이 사라진다.

| ρ | W = 8 | 12 | 16 | δg/tan²(πρ/2) (W = 16) |
|---|---|---|---|---|
| 0.10 | 0.014035 | 0.013946 | 0.013914 | 0.555 |
| 0.20 | 0.060152 | 0.059672 | 0.059501 | 0.564 |
| 0.30 | 0.149861 | 0.148686 | 0.148101 | 0.570 |
| 0.40 | 0.305246 | 0.308423 | 0.308052 | 0.584 |

- W = 8에서 16까지의 변화가 1% 이내이고, 마지막 두 폭의 차는 0.1–0.2%다. 전체 표는 `data/full_vs_boundary/dg.csv`.
- ρ → 0에서 δg → 0인 것은 얼어붙은 가장자리에서는 빈칸 하나가 안쪽으로 들어갈 자유가 없기 때문이다. 온전한 Aztec diamond의
  한 쌍 계산도 같다. 전체/경계 쌍 가중치 비가 N = 12에서 2.09, N = 26에서 1.49로 줄어 1로 간다(`dilute.py`).
- 범위는 ρ ≤ 0.41이다. x < 0.3 (ρ의 최댓값 > 0.39)에는 격자 범위를 넓힌 계산이 필요하다.
- ρ² 계수(tan² 앞의 0.545)의 해석적 유도는 하지 못했다.
